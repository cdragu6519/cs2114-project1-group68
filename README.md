## How to Compile ( Works for Linux, Windows, macOS )

1. Download the repository.
2. Open a terminal.
3. Go to the folder containing the download ( likely cd Downloads ). 
4. Once in the correct folder, unzip the project.
```bash
unzip cs2114-project1-group68-main.zip
```
5. Compile all Java source files:
```bash
javac *.java
```
4. Then run the MainMenu.java class.
```bash
java MainMenu
```
